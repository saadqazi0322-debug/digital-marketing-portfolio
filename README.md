# Digital Marketing Expert

A responsive, premium dark portfolio website for **Digital Marketing Expert**, styled in black and purple.

## Included sections
- Hero introduction and call to action
- SEO, Social Media Marketing, Google Ads, Content Marketing, Email Marketing and Website Design
- Strategy and process overview
- About section
- WhatsApp contact link

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages** from the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to finish deploying. Your site address will appear in the Pages settings.

## Customise
- Edit the page copy in `index.html`.
- Change colours and layout in `styles.css`.
- Update interactions in `script.js`.
- The WhatsApp contact link is currently set to the number provided for this project. Update the `wa.me` URL in `index.html` if the contact number changes.

Built with HTML, CSS and vanilla JavaScript. No build step required.
